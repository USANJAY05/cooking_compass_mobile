# MUVETH Kitchen Brand System

## Brand hierarchy

- Parent brand: **MUVETH**
- Parent tagline: **Three Dimensions. One Life.**
- Current product: **MUVETH Kitchen**
- Product tagline: **Cook. Nourish. Move.**

Future products can follow the same structure: `MUVETH Fit`, `MUVETH Finance`, `MUVETH Learn`, etc.

## Visual system

### Core colors

| Role | Hex |
|---|---|
| MUVETH Navy | `#172554` |
| Kitchen Green | `#22C55E` |
| Kitchen Green Dark | `#15803D` |
| Kitchen Green Light | `#DCFCE7` |
| App Background | `#F7FAF7` |
| Primary Text | `#132238` |
| Secondary Text | `#52606D` |

### Typography

- Display / brand: **Avenir Next** on iOS
- Android fallback: **sans-serif**
- Body: same family to keep the product cohesive
- Use 800–900 weight for major headings and 500–700 for supporting UI.
